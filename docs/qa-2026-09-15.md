## 4. 失敗メモ（つまずいたこと）

- **`npm i --no-save` は前回の `--no-save` を消す**: purgecss を入れると playwright が消え、playwright を入れると purgecss が消える。
  両方使うときは1コマンドで同時に入れる（`npm i --no-save playwright@1.56.1 purgecss@7.0.2`）。E2E 実行中に消すと途中で落ちる可能性がある。
- **`pkill -f "<文字列>"` は自分のシェルも殺す**: コマンド文字列に同じ文字列が含まれるため。ポートから PID を引いて `kill` する。
- **生成スクリプトでブロックを外すときの改行**: `\n<!-- … -->…</section>\n` を `"\n"` に置換すると空行が1行増えて生成物ドリフトになる。`""` に置換する。
- **サンドボックスから `denkilp.builders-job.com` / `xchange-inc.com` は到達不可**（egress 遮断）。本番/HPの表示は GitHub ランナー（probe-status）かオーナーの目視で確認する。
