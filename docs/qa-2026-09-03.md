## 3. 監査で見えたが「直さない」と判断したもの

| 事象 | 判断 |
|---|---|
| `target="_blank"` に `rel="noopener"` が無いリンク（108ファイル） | 現行ブラウザ（Chrome 88+ / Safari 12.1+ / Firefox 79+）は `_blank` に暗黙の noopener を適用するため実害なし。生成物（thanks-v2/p・variant・meta-lp）を含む108本の一斉置換は得るものに対して差分が大きすぎる |
| `<img>` に width/height が無い（62ファイル） | FVアイコン（`.p-firstButton__icon`）と選択肢の工種アイコン（`.c-button__img img`）が対象。どちらも theme-snapshot.css と cvr-boost*.css が幅高さをCSSで固定しており（FVアイコンはモバイルで `display:none`）、寸法属性が無くても枠は動かない（8/31 の実測でも CLS 0） |
| `thanks-v2-shared.js` が head で同期読み込み（36ページ） | テスト送信判定・dataLayer初期化を本文描画前に走らせる必要があり意図的。11KB |
| thanks・meta-lp・v2-deploy などの description/OGP 欠落 | すべて noindex またはHTML断片で、検索・共有の対象外 |
| `nenshu-shindan/cr/*` に viewport が無い | `ad-cr/` への即時リダイレクトのみの stub |
| 直近の CI が別ブランチ `claude/qa-check-job-site-optimization-8d88ls` で走っている | 9/3 09:15 のコミット c1ee82d は `docs/qa-2026-09-01-full-qa-and-cvr-tips.md` に「求人検索の期待値レンズのUX監査7項目」を足しただけ（コード変更なし）。main との差分はその1ファイル30行 |
