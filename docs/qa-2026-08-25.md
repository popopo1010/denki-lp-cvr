# 品質チェック・軽量化ラウンド（2026-08-25）

対象: `denki-lp-cvr` 全体。前回ラウンド（`docs/qa-2026-08-22.md`）で機能面の網は張り終えているため、
今回は **配信の無駄（ネットワーク軽量化）** を全数スキャンした。既存の静的チェック9本・
実ブラウザE2Eはすべて緑の状態から開始。

## 1. 直したもの

### A. ページに存在しない画像を preload していた（meta-lp-v2 ×4本）

`meta-lp-v2/denkikouji`・`meta-lp-v2/sekoukanri-{kentiku,doboku,denkisekou}` の4本は
テキストFV（`.meta-fv`）でヒーロー画像を一切使わないのに、
`first_banner0103.webp` / `sekoukanri_hero.webp`（64〜70KB）を **高優先度で preload** していた。
Meta広告の着地ページ＝アプリ内ブラウザの低速回線が主流の場所で、
**使われない64〜70KBが毎回クリティカルパスを奪っていた**。preload行を削除。

検出方法: 全190HTMLについて「preload した URL がそのページの他の場所（img/source/srcset）で
使われているか」を機械照合した。

### B. preload と実際に読む画像のURLが食い違っていた（自前LP ×6本）

`自前LP/{denkikouji,denkikouji-v2,sekoukanri,sekoukanri-kentiku,sekoukanri-doboku,sekoukanri-denkisekou}` は
preload が **WPテーマ由来の絶対URL**、実際の `<picture>` は **相対 `../assets/img/first_banner0103.webp`** を
参照しており、**FV画像（LCP）が二重にダウンロード**されていた（preload分64KBが丸ごと無駄）。
preload の href を実際に読むURLへ一致させた。表示されるピクセルは一切変わらない。

### C. HTML minify の対象外だったLPファミリーを deploy に追加（55ファイル）

`deploy.yml` の HTML minify は v2系・top-level非v2・thanks-v2 だけを列挙しており、
**meta-lp / meta-lp-v2 / nenshu-shindan / nenshu-shindan-v2 / WPLP非v2 / 自前LP非v2 / denkikouji-v3〜v6** は
生HTMLのまま配信されていた（広告着地の本番ページ）。対象に追加。
合計 1,374KB → 1,175KB（リポジトリ原本は不変・デプロイ時のみ。既存27ファイルと同じフラグ）。

検証: デプロイと同一コマンド（html-minifier-terser@7.2.0・同一フラグ）で55ファイルを
ローカルでminifyし、その状態で **新規追加ファミリーの全フォームLP 38本を実ブラウザE2E**
（FV表示→送信可能・自己修復・load前クリック・アプリ内ブラウザ余白）に通して確認した。

### D. FV画像 `<img>` の width/height 属性が二重に付いていた（sekoukanri v2系 ×8本）

`sekoukanri-*-v2`（top-level 4本・自前LP 4本）のヒーロー `<img>` に
`width="1200" height="727"` が2回書かれていた。後勝ちで実害はないが、不正なHTMLなので1つに整理。

## 2. 直さずに報告するもの（表示に関わるためSTG実機確認が必要）

**モバイル用 `-sp` 画像変種の未展開（28本）**: 主要LP（`denkikouji/`・`sekoukanri/` 系）は
FVに `<source media="(max-width:767px)" srcset="…-sp.webp">`（480w・21〜23KB）を使うが、
以下はモバイルでもフル画像（64〜101KB）を配っている:

- WPLP ×10 / 自前LP ×10 / nenshu-shindan(±v2) ×7 / top-level `denkikouji-v2`

`-sp` アセット（`assets/img/first_banner0103-sp.webp` 480x288・`sekoukanri_hero-sp.webp` 480x291）は
既に本番の主要LPで配信実績がある。展開すればモバイルLCP画像が 1/3〜1/5 になるが、
**FVの表示物が変わる変更**なので CLAUDE.md のルール上、STGスマホ実機確認とセットで行うこと。
あわせて width/height 未指定のFV（非v2ミラー20本、自前LP実測 960x576）も同時に揃えるとよい。

補足: 画像ファイル自体の再圧縮は不要（2026-08-19 から `optimize-images.mjs` が
`assets/img`・`自前LP/assets/img`・`ad-cr/assets` をデプロイ時に再圧縮している。
`自前LP/assets/img/first_banner0103.jpg` 450KB もランナー上で圧縮されてから配信される）。
